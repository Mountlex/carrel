# Carrel v0.7.0

This minor release improves the mobile experience, account security, offline reading, and compilation reliability.

- Papers, repositories, and settings share consistent iOS card styling. Repository names retain their compact layout, with sync status shown as a colored dot. Larger text, onboarding, and accessibility feedback are improved.
- Mobile sign-in uses one-time authorization codes with PKCE, short-lived access tokens, and rotating refresh tokens. Signing out revokes the session; settings adds account deletion and a privacy-policy link.
- The iOS library persists per account for offline use. Cached PDFs are validated, downloads are bounded, and the reader includes document search and build diagnostics.
- Compilation handles missing dependencies, queue cancellation, process timeouts, and diagnostic reporting more reliably. Release checks exercise real LaTeX engines, PDF output, and thumbnails.
- The iOS app uses Swift 6 with concurrency checking and Convex Swift 0.8.1. CI covers the iOS app alongside frontend/backend regression checks and compiler tests.

The release workflow deploys Convex and the website, plus the LaTeX service when changed. The iOS binary is distributed separately after the supporting services are deployed. Existing mobile clients retain their legacy sign-in flow; the new session protections apply to sessions created through the updated flow.

See the [iOS changes and verification](../ios-improvements/README.md) and [compilation checks](../compilation-reliability.md) for validation details and remaining release checks.
